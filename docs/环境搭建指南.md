## 2. 软件安装

### 2.1 安装 Node.js

**macOS (使用 Homebrew):**
```bash
brew install node@20
```

**Windows:**
1. 访问 https://nodejs.org/
2. 下载 LTS 版本 (20.x)
3. 运行安装程序，一路 Next

**验证安装:**
```bash
node -v    # 应显示 v20.x.x
npm -v     # 应显示 10.x.x
```

---

### 2.2 安装 Java 17

**macOS (使用 Homebrew):**
```bash
brew install openjdk@17

# 添加到环境变量
echo 'export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

**Windows:**
1. 访问 https://adoptium.net/
2. 下载 Temurin 17 (LTS)
3. 运行安装程序
4. 安装时勾选 "Set JAVA_HOME variable"

**验证安装:**
```bash
java -version   # 应显示 openjdk version "17.x.x"
```

---

### 2.3 安装 Docker

**macOS:**
1. 访问 https://www.docker.com/products/docker-desktop/
2. 下载 Docker Desktop for Mac
3. 安装并启动 Docker Desktop

**Windows:**
1. 访问 https://www.docker.com/products/docker-desktop/
2. 下载 Docker Desktop for Windows
3. 安装并启动 Docker Desktop
4. 如果提示需要 WSL2，按提示安装

**验证安装:**
```bash
docker --version   # 应显示 Docker version 24.x.x
docker-compose --version   # 应显示 Docker Compose version v2.x.x
```

---

### 2.4 安装 Git

**macOS:**
```bash
brew install git
```

**Windows:**
1. 访问 https://git-scm.com/download/win
2. 下载并安装

**验证安装:**
```bash
git --version   # 应显示 git version 2.x.x
```

## 3. 数据库配置 (Docker)

### 3.1 启动 PostgreSQL 容器

```bash
# 创建并启动 PostgreSQL 容器
docker run -d \
  --name travel-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres123 \
  -e POSTGRES_DB=travel_db \
  -p 5432:5432 \
  -v travel_data:/var/lib/postgresql/data \
  postgres:14
```

**参数说明:**
| 参数 | 说明 |
|------|------|
| `--name travel-postgres` | 容器名称 |
| `-e POSTGRES_USER` | 数据库用户名 |
| `-e POSTGRES_PASSWORD` | 数据库密码 |
| `-e POSTGRES_DB` | 自动创建的数据库名 |
| `-p 5432:5432` | 端口映射 |
| `-v travel_data` | 数据持久化卷 |

### 3.2 常用 Docker 命令

```bash
# 查看容器状态
docker ps

# 停止容器
docker stop travel-postgres

# 启动容器 (电脑重启后)
docker start travel-postgres

# 查看容器日志
docker logs travel-postgres

# 进入容器内的 psql
docker exec -it travel-postgres psql -U postgres -d travel_db
```

### 3.3 验证数据库

```bash
# 方式一: 通过 Docker 执行
docker exec -it travel-postgres psql -U postgres -d travel_db -c "SELECT 1;"

# 方式二: 如果本地安装了 psql 客户端
psql -h localhost -U postgres -d travel_db -c "SELECT 1;"
# 密码: postgres123
```

如果返回结果，说明数据库配置成功。

### 3.4 使用 Docker Compose (推荐)

在项目根目录创建 `docker-compose.yml` 后，可以更方便地管理:

```bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 查看日志
docker-compose logs -f postgres
```

## 5. 后端启动

### 5.1 配置数据库连接

编辑 `backend/src/main/resources/application.properties`:

```properties
# 数据库配置 (Docker 容器)
spring.datasource.url=jdbc:postgresql://localhost:5432/travel_db
spring.datasource.username=postgres
spring.datasource.password=postgres123

# JPA 配置
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```

> ⚠️ 密码要与 Docker 启动时设置的 `POSTGRES_PASSWORD` 一致

### 5.2 安装依赖并启动

**方式一: 命令行**
```bash
cd backend

# macOS/Linux
./mvnw spring-boot:run

# Windows
mvnw.cmd spring-boot:run
```

**方式二: IntelliJ IDEA**
1. 用 IDEA 打开 `backend` 文件夹
2. 等待 Maven 自动下载依赖 (首次可能需要几分钟)
3. 找到 `BackendApplication.java`
4. 右键 → Run 'BackendApplication'

### 5.3 验证后端启动

看到以下日志说明启动成功:
```
Started BackendApplication in x.xxx seconds
Tomcat started on port(s): 8080
```

访问 http://localhost:8080/api/regions 应返回 JSON 数据。

## 6. 前端启动

### 6.1 安装依赖

```bash
cd frontend

# 安装所有依赖
npm install
```

> ⚠️ 首次安装可能需要 2-5 分钟，请耐心等待。

### 6.2 配置高德地图 (可选)

如果需要使用地图功能:

1. 访问 https://lbs.amap.com/ 注册账号
2. 创建应用，获取 Web JS API Key
3. 编辑 `frontend/src/config/amap.ts`:

```typescript
export const AMAP_CONFIG = {
  key: '你的高德地图Key',  // 替换这里
  // ...
};
```

### 6.3 启动开发服务器

```bash
npm run dev
```

看到以下输出说明启动成功:
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

## 8. 常见问题

### Q1: npm install 报错

**问题**: 网络问题导致依赖下载失败

**解决**:
```bash
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

---

### Q2: 后端启动报数据库连接失败

**问题**: `Connection refused` 或 `password authentication failed`

**解决**:
1. 确认 Docker 容器正在运行:
   ```bash
   docker ps
   
   # 如果没有看到 travel-postgres，启动它:
   docker start travel-postgres
   ```

2. 确认容器端口映射正确:
   ```bash
   docker port travel-postgres
   # 应显示: 5432/tcp -> 0.0.0.0:5432
   ```

3. 测试数据库连接:
   ```bash
   docker exec -it travel-postgres psql -U postgres -d travel_db
   ```

4. 检查 `application.properties` 中的密码是否与 Docker 启动时一致

---

### Q3: 前端页面空白

**问题**: 控制台报 CORS 错误

**解决**: 确保后端已启动，且配置了跨域:

后端 `application.properties` 应包含:
```properties
# CORS 配置
spring.web.cors.allowed-origins=http://localhost:5173
```

---

### Q4: Maven 下载依赖很慢

**解决**: 配置阿里云镜像

编辑 `~/.m2/settings.xml` (没有则创建):
```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <name>Aliyun Maven</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

---

### Q5: 端口被占用

**问题**: `Port 8080 is already in use`

**解决**:
```bash
# 查找占用端口的进程
# macOS/Linux
lsof -i :8080

# Windows
netstat -ano | findstr :8080

# 结束进程
kill -9 <PID>
```

或修改端口:
- 后端: `application.properties` 添加 `server.port=8081`
- 前端: `vite.config.ts` 修改 `server.port`

---

### Q6: Java 版本不对

**问题**: `Unsupported class file major version 61`

**解决**: 确保使用 Java 17+
```bash
java -version

# 如果版本不对，检查 JAVA_HOME 环境变量
echo $JAVA_HOME
```
