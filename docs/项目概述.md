# 智游天下 - 智能旅游规划系统

## 项目简介

智游天下是一个基于Vue3和Spring Boot的智能旅游规划系统，包含用户端小程序和后台管理系统两部分。系统提供景点浏览、酒店预订、美食推荐、智能行程规划、社交互动等功能，为用户提供一站式旅游服务体验。

## 功能模块

### 用户端功能
1. **景点模块** - 景点浏览、搜索、详情、评论、收藏
2. **酒店模块** - 酒店列表、详情、房型、预订
3. **美食模块** - 美食推荐、详情、评论
4. **行程规划** - 智能推荐、自定义行程、行程保存
5. **订单模块** - 门票预订、订单管理
6. **社交模块** - 用户关注、私信、通知
7. **个人中心** - 个人信息、收藏、成就

### 后台管理功能
1. **数据统计** - 用户、景点、订单等数据概览
2. **用户管理** - 用户列表、收藏、行程、成就
3. **景点管理** - 景点增删改查、状态管理
4. **酒店管理** - 酒店信息管理
5. **美食管理** - 美食信息管理
6. **地区管理** - 地区层级管理
7. **订单管理** - 订单查看、状态修改
8. **评论管理** - 评论审核、删除
9. **社交管理** - 消息、关注关系管理
