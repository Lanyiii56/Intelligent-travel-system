# 🚀 智能旅游平台 - 项目开发步骤

> 本文档描述项目的整体开发流程和各阶段任务

---

## 📋 项目概述

| 项目 | 说明 |
|------|------|
| **项目名称** | 智能旅游平台 |
| **团队规模** | 4人 |
| **技术栈** | Vue 3 + Spring Boot 3 + PostgreSQL |
| **开发周期** | 4周 |

---

## 👥 团队分工

| 成员 | 模块 | 前端目录 | 后端目录 |
|------|------|----------|----------|
| 成员1 | 用户认证 | `frontend/src/modules/auth/` + `pages/Login.vue` | `backend/.../controller/AuthController.java` |
| 成员2 | 景点管理 | `frontend/src/modules/spot/` + `pages/Home.vue,Spots.vue` | `backend/.../controller/SpotController.java` |
| 成员3 | 智能推荐 | `frontend/src/modules/recommend/` + `pages/Recommend.vue` | `backend/.../controller/RecommendController.java` |
| 成员4 | 订单社交 | `frontend/src/modules/order/` + `pages/Reservation.vue` | `backend/.../controller/OrderController.java` |

## 1. 需求分析与项目规划

### 目标

- 确定平台的核心功能和需求
- 明确用户角色和不同功能模块
- 制定项目开发周期与里程碑

### 核心功能

| 功能模块 | 负责人 | 优先级 |
|----------|--------|--------|
| 用户注册登录 | 成员1 | P0 |
| 景点列表展示 | 成员2 | P0 |
| 智能推荐算法 | 成员3 | P0 |
| 订单预订管理 | 成员4 | P1 |
| 评论收藏功能 | 成员4 | P1 |
| 地图路线展示 | 成员3 | P1 |

### 技术选型

- **前端**: Vue 3 + TypeScript + Vite + Element Plus + 高德地图
- **后端**: Spring Boot 3 + Spring Data JPA + Spring Security + JWT
- **数据库**: PostgreSQL 14 (Docker 容器)
- **缓存**: Redis (可选)

---

## 2. 环境搭建

### 目标

- 搭建开发环境，确保前后端、数据库等可以无缝协作

### 环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| Node.js | >= 20.x | 前端运行环境 |
| Java | 17+ | 后端运行环境 |
| Docker | 最新版 | 数据库容器 |
| Git | 最新版 | 版本控制 |

### 快速启动

```bash
# 1. 启动数据库
docker-compose up -d

# 2. 启动后端
cd backend && ./mvnw spring-boot:run

# 3. 启动前端
cd frontend && npm install && npm run dev
```

> 详细步骤请参考 [环境搭建指南.md](./环境搭建指南.md) 和 [快速启动.md](./快速启动.md)

## 3. 数据库设计

### 数据库表结构

| 表名 | 说明 | 负责人 |
|------|------|--------|
| `users` | 用户信息 | 成员1 |
| `regions` | 地区信息 | 成员2 |
| `spots` | 景点信息 | 成员2 |
| `activities` | 活动信息 | 成员2 |
| `recommend_logs` | 推荐日志 | 成员3 |
| `orders` | 订单信息 | 成员4 |
| `comments` | 评论信息 | 成员4 |
| `favorites` | 收藏信息 | 成员4 |

### 表关系

```
users ──┬── orders (1:N)
        ├── comments (1:N)
        ├── favorites (1:N)
        └── recommend_logs (1:N)

regions ──── spots (1:N)

spots ──┬── orders (1:N)
        ├── comments (1:N)
        └── favorites (1:N)
```

## 4. 功能模块开发

### 模块A: 用户认证 (成员1)

| 功能 | 前端文件 | 后端文件 | API |
|------|----------|----------|-----|
| 用户登录 | `pages/Login.vue` | `AuthController.java` | `POST /api/auth/login` |
| 用户注册 | `pages/Login.vue` | `AuthController.java` | `POST /api/auth/register` |
| 个人中心 | `pages/Profile.vue` | `AuthController.java` | `GET /api/auth/me` |
| 修改资料 | `pages/Profile.vue` | `AuthController.java` | `PUT /api/auth/profile` |

### 模块B: 景点管理 (成员2)

| 功能 | 前端文件 | 后端文件 | API |
|------|----------|----------|-----|
| 首页展示 | `pages/Home.vue` | `SpotController.java` | `GET /api/spots/hot` |
| 景点列表 | `pages/Spots.vue` | `SpotController.java` | `GET /api/spots` |
| 景点详情 | `pages/SpotDetail.vue` | `SpotController.java` | `GET /api/spots/{id}` |
| 地区筛选 | `pages/Spots.vue` | `RegionController.java` | `GET /api/regions` |

### 模块C: 智能推荐 (成员3)

| 功能 | 前端文件 | 后端文件 | API |
|------|----------|----------|-----|
| 智能推荐 | `pages/SmartRecommend.vue` | `RecommendController.java` | `POST /api/recommend/smart` |
| 基础推荐 | `pages/Recommend.vue` | `RecommendController.java` | `GET /api/recommend` |
| 路线规划 | `pages/SmartRecommend.vue` | `RecommendService.java` | - |
| 地图展示 | `modules/recommend/components/TravelMap.vue` | - | 高德地图API |

### 模块D: 订单社交 (成员4)

| 功能 | 前端文件 | 后端文件 | API |
|------|----------|----------|-----|
| 创建订单 | `pages/Reservation.vue` | `OrderController.java` | `POST /api/orders` |
| 订单列表 | `pages/Profile.vue` | `OrderController.java` | `GET /api/orders/user/{userId}` |
| 发表评论 | `modules/order/components/CommentList.vue` | `SocialController.java` | `POST /api/social/comments` |
| 收藏景点 | `pages/SpotDetail.vue` | `SocialController.java` | `POST /api/social/favorites` |
