# 智能旅游系统 - 项目代码讲解

## 一、项目概述

本项目是一个智能旅游推荐系统，采用前后端分离架构：
- **前端**：Vue 3 + TypeScript + Element Plus
- **后端**：Spring Boot 3 + JPA + PostgreSQL
- **特色功能**：智能行程规划、景点推荐、美食推荐、评论互动

## 五、核心功能实现

### 5.1 智能行程推荐

**前端**：`SmartRecommend.vue`
- 用户选择：地区、天数、预算、年龄、偏好
- 调用推荐 API
- 展示推荐结果：景点列表、路线地图、费用明细
- 支持保存行程

**后端**：`RecommendService.java`
```java
public RecommendResult smartRecommend(RecommendRequest req) {
    // 1. 获取地区景点
    List<Spot> spots = spotRepository.findByRegionId(req.getRegionId());
    
    // 2. 过滤：预算、年龄
    spots = filterByBudget(spots, req.getBudget());
    spots = filterByAge(spots, req.getAgeMin(), req.getAgeMax());
    
    // 3. 排序：评分 + 偏好匹配
    spots = sortByPreference(spots, req.getPreferences());
    
    // 4. 分配到每天
    List<DayPlan> dayPlans = allocateToDays(spots, req.getDays());
    
    // 5. 计算路线和费用
    RouteInfo route = routeService.planRoute(dayPlans);
    CostInfo cost = calculateCost(dayPlans, route);
    
    // 6. 推荐美食
    List<Food> foods = foodService.recommendForTrip(req.getRegionId());
    
    return new RecommendResult(dayPlans, route, cost, foods);
}
```

### 5.3 用户数据隔离

**实现方式**：
- 所有用户数据（收藏、订单、行程）通过 `userId` 关联
- 前端本地存储（如点赞状态）按用户 ID 区分 key
- 退出登录时清除用户状态

```typescript
// 本地存储 key 格式
`comment_likes_${userId}_${commentId}`
`food_comment_likes_${userId}_${commentId}`
`travel_itineraries_${userId}`
```

## 七、技术栈总结
