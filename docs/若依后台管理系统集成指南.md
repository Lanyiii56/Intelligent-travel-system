│   http://localhost:8080  │        │   http://localhost:8081  │

│   backend/               │        │   ruoyi-admin/           │

              │                                    │
              └────────────────┬───────────────────┘

          ┌─────────────────────────────────────────┐
          │         Sealos Cloud 云服务              │
          │  ┌─────────────┐    ┌─────────────┐     │
          │  │   MySQL     │    │   Redis     │     │

          │  └─────────────┘    └─────────────┘     │

```

### 1.2 云服务优势

- **数据统一**：所有开发者、测试者共用同一数据库，数据实时同步
- **无需本地安装**：不需要在本地安装 MySQL、Redis，Docker 容器可以停用
- **团队协作**：多人开发时数据一致，便于联调测试
- **部署简单**：生产环境和开发环境使用相同配置

```

### 4.6 智游天下前台项目数据库迁移（重要）

由于统一使用 MySQL 云服务，需要修改现有的智游天下前台项目（backend）配置。

#### 第一步：修改 pom.xml 依赖

将 PostgreSQL 驱动改为 MySQL 驱动：

**修改 `Intelligent-travel-system/backend/pom.xml`：**

```xml
<!-- 删除 PostgreSQL 驱动 -->
<!-- <dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency> -->

<!-- 添加 MySQL 驱动 -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

#### 第二步：修改数据库连接配置

**修改 `Intelligent-travel-system/backend/src/main/resources/application.properties`：**

```properties
# 数据库配置 - Sealos Cloud MySQL
spring.datasource.url=jdbc:mysql://dbconn.sealosbja.site:38153/zzyl?useUnicode=true&characterEncoding=utf8&useSSL=true&serverTimezone=GMT%2B8
spring.datasource.username=root
spring.datasource.password=8v48dvmm
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA 配置
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```

#### 第三步：数据迁移

需要将现有的 PostgreSQL 数据迁移到 MySQL。可以使用以下方法：

1. **方法一：JPA 自动建表**
   - 设置 `spring.jpa.hibernate.ddl-auto=create`（首次运行）
   - 启动后端，JPA 会自动创建表结构
   - 然后改回 `update`

2. **方法二：导出导入**
   - 从 PostgreSQL 导出数据
   - 转换 SQL 语法后导入 MySQL

#### 第四步：注意事项

| PostgreSQL | MySQL | 说明 |
|------------|-------|------|
| `SERIAL` | `AUTO_INCREMENT` | 自增主键 |
| `BOOLEAN` | `TINYINT(1)` | 布尔类型 |
| `TEXT` | `TEXT` | 长文本 |
| `TIMESTAMP` | `DATETIME` | 时间戳 |

在若依中配置多数据源，连接你现有的 PostgreSQL 数据库：

```yaml
# application-druid.yml
spring:
    datasource:
        druid:
            # 主库 - 若依系统表 (MySQL)
            master:
                url: jdbc:mysql://...
            # 从库 - 业务数据 (PostgreSQL)
            slave:
                enabled: true
                url: jdbc:postgresql://你的PostgreSQL地址:5432/postgres
                username: postgres
                password: 你的密码
                driver-class-name: org.postgresql.Driver
```

**方案 B：数据同步到同一数据库**

将现有业务表迁移到 MySQL，与若依系统表共用一个数据库。

## 八、常见问题

### 8.1 Maven 下载依赖慢

配置阿里云镜像，编辑 `~/.m2/settings.xml`：

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### 8.2 Redis 连接失败

确保 Redis 服务已启动：

```bash
# 检查 Redis 状态
redis-cli ping

# 如果未启动
brew services start redis
```

### 8.3 数据库连接失败

检查：
1. Sealos Cloud 数据库是否允许外部连接
2. 数据库地址、端口、用户名、密码是否正确
3. 防火墙是否放行
