# 快速启动指南

> 3分钟启动项目

## 前置条件

| 环境 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | 18+ | 前端运行环境 |
| Java | 17+ | 后端运行环境 |
| Maven | 3.8+ | Java依赖管理 |

## 项目结构

```
Zxtx/
├── Intelligent-Travel-System/  # 用户端小程序
│   ├── frontend/               # Vue3前端 (端口5173)
│   └── backend/                # Spring Boot后端 (端口8080)
├── TravelAdmin/                # 后台管理后端 (端口8081)
└── Zxtx-Vue/                   # 后台管理前端 (端口1024)
```

---

## 一、启动用户端小程序

### 1.1 启动后端服务
```bash
cd Intelligent-Travel-System/backend
mvn spring-boot:run
```
✅ 后端运行在 http://localhost:8080

### 1.2 启动前端服务
```bash
cd Intelligent-Travel-System/frontend
npm install
npm run dev
```
✅ 前端运行在 http://localhost:5173

---

## 二、启动后台管理系统

### 2.1 启动后台后端
```bash
cd TravelAdmin
mvn spring-boot:run -pl travel-admin
```
✅ 后端运行在 http://localhost:8081

### 2.2 启动后台前端
```bash
cd Zxtx-Vue
npm install
npm run dev
```
✅ 前端运行在 http://localhost:1024

## 四、数据库配置

数据库已配置为远程数据库，无需本地安装MySQL。

如需修改数据库配置：

**小程序后端** (`Intelligent-Travel-System/backend/src/main/resources/application.properties`)
```properties
spring.datasource.url=jdbc:mysql://your-host:3306/zxtx
spring.datasource.username=your-username
spring.datasource.password=your-password
```

**后台管理后端** (`TravelAdmin/travel-admin/src/main/resources/application-druid.yml`)
```yaml
url: jdbc:mysql://your-host:3306/zxtx
username: your-username
password: your-password
```

## 五、常见问题

### Q1: 端口被占用
**解决方案：**
- 小程序后端：修改 `application.properties` 中的 `server.port=8080`
- 后台后端：修改 `application.yml` 中的 `server.port=8081`
- 前端：修改 `vite.config.ts` 中的端口配置

### Q2: 依赖安装失败
**解决方案：**
```bash
# 清除npm缓存
npm cache clean --force
# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### Q3: Maven编译失败
**解决方案：**
```bash
# 清除Maven缓存
mvn clean
# 强制更新依赖
mvn install -U
```

### Q4: 页面显示404
**解决方案：**
1. 确认后端服务已启动
2. 检查API地址配置是否正确
3. 查看浏览器控制台错误信息

## 六、开发建议

1. **先启动后端，再启动前端**
2. **修改代码后，前端会自动热更新**
3. **后端修改需要重启服务**
4. **使用Chrome开发者工具调试**
