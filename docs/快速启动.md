# ⚡ 快速启动 (TL;DR)

> 给已经有开发环境的同学，3 分钟启动项目

## 前置条件

确保已安装:
- Node.js 20+
- Java 17+
- Docker Desktop

## 一键启动

### 1️⃣ 启动数据库 (Docker)

```bash
# 方式一: 使用 docker-compose (推荐)
docker-compose up -d

# 方式二: 单独启动 PostgreSQL
docker run -d \
  --name travel-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres123 \
  -e POSTGRES_DB=travel_db \
  -p 5432:5432 \
  postgres:14
```

### 2️⃣ 启动后端

```bash
cd backend
./mvnw spring-boot:run
```

> 默认配置已设置好，无需修改 (密码: postgres123)

### 3️⃣ 启动前端 (新开终端)

```bash
cd frontend
npm install
npm run dev
```

### 4️⃣ 访问

打开 http://localhost:5173

---

## 端口说明

| 服务 | 端口 |
|------|------|
| 前端 | 5173 |
| 后端 | 8080 |
| 数据库 | 5432 |
| Redis | 6379 |

## Docker 常用命令

```bash
# 查看容器状态
docker ps

# 停止所有服务
docker-compose down

# 重启数据库
docker-compose restart postgres

# 电脑重启后启动服务
docker-compose up -d
```

## 测试账号

首次启动会自动初始化测试数据，可直接使用智能推荐功能。

> 📝 **注意**: 登录功能需要先注册账号，系统暂未预置测试账号。
