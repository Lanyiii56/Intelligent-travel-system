## 🔧 配置文件版本

### 后端 application.properties

```properties
# 数据库 (与 docker-compose.yml 一致)
spring.datasource.url=jdbc:postgresql://localhost:5432/travel_db
spring.datasource.username=postgres
spring.datasource.password=postgres123

# Redis
spring.data.redis.host=localhost
spring.data.redis.port=6379

# 服务端口
server.port=8080
```

### 前端 vite.config.ts

```typescript
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
      },
    },
  },
})
```

## ⚠️ 版本兼容性说明

### 已验证的兼容组合

| 组合 | 状态 |
|------|------|
| Spring Boot 3.2 + Java 17 | ✅ 兼容 |
| Vue 3.4 + Pinia 2.1 | ✅ 兼容 |
| Vue 3.4 + Vue Router 4.3 | ✅ 兼容 |
| Vue 3.4 + Element Plus 2.6 | ✅ 兼容 |
| Vite 5.0 + Vue 3.4 | ✅ 兼容 |
| TypeScript 5.3 + Vue 3.4 | ✅ 兼容 |
| PostgreSQL 14 + Spring Data JPA | ✅ 兼容 |

### 注意事项

1. **Pinia 版本**: 必须使用 `2.x` 版本，`3.x` 尚未发布稳定版
2. **Java 版本**: Spring Boot 3.x 要求 Java 17+，不能使用 Java 8 或 11
3. **Node.js 版本**: Vite 5.x 要求 Node.js 18+，推荐使用 20.x LTS
4. **Element Plus**: 2.6.x 与 Vue 3.4 完全兼容

## 🔄 依赖更新规则

### 禁止随意更新

以下依赖版本已锁定，**禁止**团队成员自行更新：

- `vue` - 核心框架
- `pinia` - 状态管理
- `element-plus` - UI 组件库
- `spring-boot-starter-parent` - 后端核心

### 允许小版本更新

以下依赖可以更新小版本 (如 1.6.8 → 1.6.9)：

- `axios`
- `dayjs`
- `echarts`

### 更新流程

1. 在群里通知团队
2. 在本地测试通过
3. 更新本文档
4. 提交代码

## 📋 快速检查清单

团队成员在开始开发前，请确认：

- [ ] Node.js 版本 >= 20.x (`node -v`)
- [ ] Java 版本 = 17 (`java -version`)
- [ ] Docker 已安装并运行 (`docker --version`)
- [ ] 数据库容器已启动 (`docker ps`)
- [ ] 前端依赖已安装 (`npm install`)
- [ ] 后端能正常启动 (`./mvnw spring-boot:run`)
- [ ] 前端能正常启动 (`npm run dev`)

## 📞 遇到版本问题？

1. 先检查本文档的版本要求
2. 删除 `node_modules` 和 `package-lock.json`，重新 `npm install`
3. 在群里反馈问题，附上错误信息
