# 数据库设计文档

## 数据库信息

- **数据库类型**: MySQL 8.0+
- **数据库名**: zxtx
- **字符集**: utf8mb4
- **排序规则**: utf8mb4_general_ci

---

| points | int | YES | 0 | 积分 |
| level | int | YES | 1 | 等级 |
| status | char(1) | YES | '0' | 状态(0正常 1停用) |
| create_time | datetime | YES | NULL | 创建时间 |
| update_time | datetime | YES | NULL | 更新时间 |
