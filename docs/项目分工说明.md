# 智游天下 - 项目分工说明

## 一、项目概述

本项目包含两个子系统：
- **用户端小程序**：面向游客的旅游服务平台
- **后台管理系统**：面向管理员的数据管理平台

---

## 二、模块划分 (4人分工)

| 成员 | 小程序模块 | 后台管理模块 | 主要职责 |
|------|------------|--------------|----------|
| **成员1** | 用户认证 | 用户管理、系统配置 | 登录注册、个人中心、后台用户管理 |
| **成员2** | 景点管理 | 景点/酒店/美食/地区管理 | 景点展示、后台数据管理 |
| **成员3** | 智能推荐 | 数据统计 | 推荐算法、行程规划、数据分析 |
| **成员4** | 订单社交 | 订单/评论/社交管理 | 预订、评论、收藏、后台审核 |

## 十二、数据同步说明

小程序和后台管理共用同一MySQL数据库：

| 操作 | 数据流向 |
|------|----------|
| 用户在小程序发评论 | → travel_comment表 → 后台可查看 |
| 后台修改景点信息 | → travel_spot表 → 小程序展示更新 |
| 用户下单 | → travel_order表 → 后台可管理 |
| 后台禁用用户 | → travel_user表 → 小程序无法登录 |
